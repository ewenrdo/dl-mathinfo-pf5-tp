# dl-mathinfo-pf5-tp


## Lancer un fichier

Les fichiers n'ont _a priori_ pas de dépendances.
Pour lancer un fichier via UTOP, il faut utiliser la commande suivante dans le terminal :

```bash
utop # #use "tp1.ml";;
```

> [!TIP]
> Pour fermer UTOP, il faut utiliser la commande `#quit;;` ou `Ctrl+D`.
